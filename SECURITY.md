# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities via [GitHub Security Advisories](https://github.com/z23/netbox-mcp-server/security/advisories/new) for this fork, or open a private security report against this repository.

Do not file public issues for security-sensitive findings.

Upstream NetBox Labs security contact (for issues also present in [netboxlabs/netbox-mcp-server](https://github.com/netboxlabs/netbox-mcp-server)): security@netboxlabs.com
